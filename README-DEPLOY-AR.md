# منصة بصائر — نسخة روابط المحاضرات

## النشر
هذه نسخة موقع ثابت (Static Website) مناسبة لـ GitHub Pages. ارفعي الملفات الموجودة في جذر ملف ZIP إلى المستودع، ثم فعّلي GitHub Pages من إعدادات المستودع.

## لا تحتاج هذه النسخة إلى
- Node.js أو Express
- LiveKit
- PostgreSQL
- Render أو أي خادم خلفي
- حسابات دخول أو كلمات مرور داخل منصة بصائر

## إعداد روابط المحاضرات
افتحي `index.html` وابحثي عن `const CONFIG=`. ضعي روابط الاجتماعات في الحقول المناسبة:

```js
const CONFIG={
  live:{
    quran:'https://meet.google.com/your-meeting',
    tajweed:'https://zoom.us/j/your-meeting',
    sharia:''
  },
  maps:{
    quran:'',
    tajweed:'',
    sharia:''
  },
  resources:{tests:'',audio:'',reports:''}
};
```

استبدلي الأمثلة بروابط الاجتماعات الفعلية. اتركي أي قيمة فارغة إذا لم يتوفر رابط بعد. لا تضعي كلمات مرور أو مفاتيح سرية في الملف.

## طريقة الاستخدام
1. تنشئ المحاضِرة اجتماعًا من Google Meet أو Zoom.
2. تنسخ رابط الدعوة.
3. تضيفه في حقل الحلقة المناسبة داخل `CONFIG.live`.
4. إذا كانت الحلقة في مكان فعلي، تضيف رابط Google Maps في `CONFIG.maps`.
5. ترفع `index.html` المعدّل إلى GitHub Pages.

عند الضغط على زر المحاضرة يفتح الرابط في نافذة جديدة. لا يحتاج الطالب إلى إنشاء حساب في منصة بصائر؛ وقد يطلب Meet أو Zoom اسمًا أو تسجيل دخول وفق إعدادات الاجتماع نفسه.
